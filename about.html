About

A studio built around craft

AionForge is an independent game studio focused on Minecraft packs, playable worlds, and the creative tools that make production faster without lowering the bar.

We care about systems players can feel, assets that hold up under real use, and packaging that is simple to install and maintain. The goal is straightforward: ship work that is worth loading.

What guides the work

  • Clarity first — players should understand what they got and how to use it.
  • Production quality — release-ready packaging, not throwaway demos.
  • Long-term maintainability — content designed to evolve cleanly.
  • Honest status — public pages stay current with real project state.

Stack & presence

Public source and studio projects live under github.com/AionForgeStudio. This website is hosted with GitHub Pages and can later move under a custom domain such as aionforge.com without changing the underlying hosting model.
